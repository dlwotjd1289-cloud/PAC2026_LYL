# PAC2026 V5 대시보드 — 지표 신뢰성·출처 검토

기준: V4 코드 및 V5 변경 사항. 이 문서는 **입력과 검증 범위의 기술 검토**이며 사용자의 PC에서 수집한 개별 측정값의 정확도를 인증하는 문서가 아닙니다. 대상은 Gazebo Fortress의 **시뮬레이션**이지 실물 산업로봇이 아닙니다.

| 화면 항목 | 실제 데이터/계산 | 검증 가능한 사실 | 검증할 수 없는 것 |

| ROBOT JOINTS x/6 | ROS 2 `/joint_states`, `j1`~`j6` 이름 존재 여부 및 최근 수신시간 | 6개 위치값이 ROS 2에서 전달됨 | 목표 추종 성공, 로봇 안전, 하드웨어 정확도 |

## 판정 기준

- **최근 수신**: 관측 파일과 해당 원본 데이터가 각각 5초 이내인 경우만 현재값으로 취급합니다. 5초 기준은 UI 표시용 개발 설정이며 로봇 안전·공정 성능 목표가 아닙니다.
- **오래된 실패**: 로그 수정 후 30초 넘으면 `이전 실행의 실패 기록`으로 표시합니다. 30초는 실행 종료 판정이 아니라 구분을 위한 UI 기준입니다.
- **메시지 6/6**은 정상 작동 비율 100%가 아닙니다. 6개의 관절 이름이 관측됐다는 의미입니다.
- **TRACKED POSES**는 필터를 거친 모델 개수이며, 박스가 없는 작업셀에서 2개로 표시될 수 있습니다.
- **카메라 2/2**도 영상 스트림 표시 가능성을 뜻할 뿐 인식 알고리즘이 정상·정확하다는 검증이 아닙니다. 브라우저에서 JPEG 디코딩 실패 시 개별 영상은 숨깁니다.
- **Controller error**는 해당 컨트롤러가 보고한 수치입니다. 별도 계측과 설정된 허용오차 없이는 합격/불합격을 결정하지 않습니다.
- **실시간 렌더링**은 Gazebo 시뮬레이션 상태를 반복 읽어 표시한다는 뜻이지 Gazebo가 계산한 모든 프레임을 그대로 전달한다는 뜻이 아닙니다.

## 앞으로 실제 성능평가를 하려면

최종 적재 성공/실패율, 컨트롤러 목표-실제 오차 분포, 95% 시간 지표, Gazebo 접촉·지지·하중, 박스 낙하/미적재, MoveIt 경로 검증 및 완료 이벤트를 **별도 실험 로그와 동일 실행 ID로 정렬**해야 합니다. 현재 대시보드 수치만으로 이 지표들을 대신할 수 없습니다.
